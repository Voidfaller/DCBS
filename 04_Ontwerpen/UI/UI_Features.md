# User Interface Features

## 1. Introduction

The automatic Dynamic Cup Balancing System is a project by 5 students for the Embedded systems course.
This document is going more in depth of how the user interface is designed

## 2. Requirements

- The user is able to change and save the correction speed and maximum tilt tolerance of the DCBS
- The user is able to change the previous settings even when it is in use using a manual override
- The user is able to see current settings and change them with simple (software) buttons 

## 3. Extra optional features

- The user is able to see some sort of fluid simulation on the display that simulates the contents of the cup
- The user is able to configure and save multiple settings groups and change between them with just one button
