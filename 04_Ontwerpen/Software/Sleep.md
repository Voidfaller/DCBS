# Sleep Functionality

## 1. When to go to sleep

- After the cup has been put down
- After configuring of the cup is finished or timeout

Always at least 2 seconds delay

## 2. When to wake up

When the cup is picked up
When the cup is being configured

Wakeup source: External wakeup

## 3. Sleep modes / Power down modes needed

Deep sleep mode

## 4. Misc

Wifi and bluetooth need to be turned off before going into sleep mode if its not needed at all times. Otherwise special sleep mode to wake up when the appropriate functions are called
Disable wakeup sources that are not used in the program
