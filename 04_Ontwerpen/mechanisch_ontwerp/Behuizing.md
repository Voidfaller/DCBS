# Mechanisch ontwerp

## 1. Onderdelen

Onderdelen:
Base (onderplaat)
Servo X-as
Servo Y-as
Inner frame (kantelplatform)
Cup holder
MPU6050 sensor
ESP32 + voeding
Display

De servo’s staan haaks op elkaar zodat ze twee richtingen kunnen corrigeren.

Beweging:
Servo 1 : kantelt links/rechts (X-axis)
Servo 2 : kantelt voor/achter (Y-axis)
