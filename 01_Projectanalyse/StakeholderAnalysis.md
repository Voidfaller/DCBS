# Stakeholder Analysis

## 1. Introduction

The automatic Dynamic Cup Balancing System is a project by 5 students for the Embedded systems course.

This document is going more in depth of all the stakeholders in the project and how they affect the project itself.

## 2. Stakeholders

The project has a few stakeholdes. These stakeholders are:
- Project owner
- Develepment team
- Users

## 3. Communication and how the project is affected

The stakeholders affect how the project is developed and. The stakeholders all want something from the project. All stakeholders are able to communicate with the development team. 

| | **Why is this stakeholder important to the project**| **Why is the project important to the stakeholder**| **What does the stakeholder want this product to be at the end**| **Communication methods of the stakeholder**|
|:-:|:-:|:-:|:-:|:-:|
|**Product Owner**| Issued the development of the project, makes the criteria for completion and makes some decisions concerning the project| Invests money in the project. Wants to see their idea created |Wants a product it can use/sell/develop further| Chat in teams, eMail, meetings|
|**Development Team**| They work on the project and make decisions concerning the project| They work on the project to pass the course| A product that meets all set course criteria| Chat in teams and meetings|
|**Users**| The users of the finished product| A good experience after the product is finished| A product that balances a cup whilst they are holding it| Internet and customer service|
